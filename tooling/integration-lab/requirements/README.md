# Installation

Le laboratoire n'a aucune dépendance Python externe. Python3.12 et Git suffisent pour ses tests, le verrou, les rapports et l'export. Les commandes des modules nécessitent leurs toolchains propres ; voir ../docs/DEPENDENCIES-LICENSES.md. Ne pas installer de modèle ou de service supplémentaire. La CI réutilise exclusivement la dépendance historique backup_prototype/requirements.txt pour sa suite existante.
