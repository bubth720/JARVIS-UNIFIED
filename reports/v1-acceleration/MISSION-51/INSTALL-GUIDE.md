# Guide Android de laboratoire — aucune installation autorisée ici

Ce sous-lot UNIFIED ne construit pas d'APK. Le parent INTERFACE fournira son lien GitHub réel, nom, SHA256, applicationId, versionCode, certificat et limites de test. **Ne pas remplacer ces champs par une URL supposée.** Aucun APK de ce guide n'est installé sur le POCO ou la Redmi sans accord distinct.

Avant toute future installation autorisée : vérifier le SHA de l'APK et son certificat dans la note de livraison, confirmer testOnly et package distinct, absence de permissions nouvelles/INTERNET si non requis, sourcecommit/tree et rapports Android de ce binaire. Une signature debug est une identité de laboratoire temporaire, pas une preuve de mise à jour sûre des applications personnelles.

Les données sont propres au paquet laboratoire. Ne pas désinstaller l'ancien JARVIS ou utiliser -r pour contourner un certificat différent. Tester création/reprise uniquement avec données publiques de fixture ; aucune migration personnelle. Pour retour arrière, conserver les exports volontaires utiles du seul laboratoire et désinstaller uniquement son package après accord ; fichiers originaux SAF et données des anciennes applications demeurent distincts.

L'application doit fonctionner offline et annoncer honnêtement modules OFF/BLOCKED. Un modèle ne s'importe qu'après campagne d'acquisition autorisée et gates ; ce guide n'en autorise aucune. Termux et Android Studio ne sont pas nécessaires pour lire les preuves ou examiner l'APK fournie.
