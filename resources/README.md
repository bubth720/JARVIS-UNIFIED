# Références de ressources

Arborescence préparatoire uniquement : TABLET, MOBILE, CENTRAL et VOICES.
Aucun poids ou profil personnel ici, aucun téléchargement automatique.

`sha256: null` signifie qu'aucun artefact exact n'est sélectionné/vérifié.
Les références Qwen3 sont initiales et évolutives. Un format vocal exige son
moteur/checkpoint et son pack exacts ; aucun profil vocal universel n'est supposé.
Les futurs artefacts privés restent hors Git dans un stockage choisi explicitement.

Voir [COMPATIBILITY.md](../COMPATIBILITY.md) et [BACKUP_FORMAT.md](../BACKUP_FORMAT.md).
