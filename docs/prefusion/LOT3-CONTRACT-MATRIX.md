## Scénario de laboratoire reproductible

`python3 -m unittest discover -s tooling/integration/lot3_tests -v` : parse une source nommée `synthetic-*.txt` ou `synthetic-*.csv`, construit une demande avec identifiants CORE candidats et empreinte SHA256, puis affiche un résultat **UNSUPPORTED**, sans réponse documentaire inventée. Le consommateur est une fixture Python, pas l'application INTERFACE ; aucun appel CORE/NEXUS/LLM/VOICE réel. Le rejeu, une citation inventée, une identité modifiée, READY et l'écriture sont refusés. Les tests des modules propriétaires ne sont pas remplacés par cette fixture.

Tous les schémas historiques `contracts/v1`, les propositions v2, les verrous, la BOM et les snapshots précédents restent inchangés. Aucun nouveau contrat n'est adopté par ce tableau.
